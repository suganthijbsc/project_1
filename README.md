📌 ShopEase – E-Commerce Frontend Website

ShopEase is a responsive e-commerce frontend website designed to provide users with a simple and interactive online shopping experience. The website allows users to browse products, explore categories, manage their shopping cart, and navigate through different sections of the online store.

🛠️ Technologies Used
HTML5
CSS3
JavaScript
✨ Key Features
🏠 Home page
🛍️ Product listing
📂 Category-based product filtering
👤 Login page UI
🛒 Shopping cart
➕ Add to cart
➖ Remove from cart
🔢 Cart item count
📱 Responsive design
🎨 Clean and user-friendly interface

📂 Project Structure
ShopEase/
│
├── index.html
├── product.html
├── cart.html
├── login.html
├── order-success.html
├── checkout.html
├── style.css
├── script.js


🎯 Project Objective

The objective of this project is to design and develop a user-friendly e-commerce frontend using HTML, CSS, and JavaScript, focusing on product browsing, category filtering, login interface, and shopping cart functionality.

Frontend Web Development Project
